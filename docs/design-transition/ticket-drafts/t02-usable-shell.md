# RASCUNHO T02 — Entregar abertura responsiva e navegação antes do 3D

**Estado: proposto, ainda não publicado.** Os IDs Txx não são números de issue.

## What to build

Permitir que o visitante leia a apresentação, navegue pelo portfólio e abra o currículo imediatamente, com a composição aprovada sobre um poster e sem esperar animações.

Contexto: portfólio existente de Kauê Ruon Cardoso; preservar a referência aprovada, navegação HTML e os contratos públicos. Esta tarefa não autoriza publicação.

## Acceptance criteria

- [ ] Usar o cumprimento, texto curto, três áreas e violeta aprovados; manter todo texto e controle em HTML acessível.
- [ ] Navegar por Projetos, Trajetória, Contato e currículo usando links reais, preservando hashes existentes.
- [ ] Usar shells novo e legado mutuamente exclusivos: o novo não monta loader, cursor, canvas ou motor global antigo.
- [ ] Exibir poster próprio sem UI duplicada; caso ainda temporário, não declarar conclusão visual e registrar o bloqueio.
- [ ] Menu móvel abre/fecha, informa seu estado e restaura foco; contatos ainda não migrados oferecem e-mail direto.
- [ ] Ser utilizável a 320 px, com teclado, zoom e ausência de JS/renderer; alvos planejados de pelo menos 44 CSS px e nenhuma rolagem horizontal.
