# T05 — Apresentar projetos com evidências e estados corretos

**Estado: publicado.** [Issue #40](https://github.com/Kauerc10/Portifolio-K.R.001/issues/40). Cópia local de consulta; o GitHub é a fonte de estado e bloqueios. Conferido em 28/10/2026.

## What to build

Permitir avaliar os projetos pelo problema, contribuição, solução, tecnologias e evidências reais, em português e inglês.

Contexto: portfólio existente de Kauê Ruon Cardoso; preservar a referência aprovada, navegação HTML e os contratos públicos. Esta tarefa não autoriza publicação.

## Acceptance criteria

- [ ] Atlas e CKF aparecem em produção; DocFácil e VECOM em desenvolvimento; Foli permanece complementar.
- [ ] Cada projeto mostra contexto e contribuição verificáveis; o Atlas descreve a redução de uma etapa de aproximadamente cinco minutos para vinte segundos.
- [ ] Links existentes continuam úteis e URLs ausentes omitem ações; não inventar demo pública para projeto privado.
- [ ] Screenshots reais são usados apenas no projeto correspondente, sem apresentar arte conceitual como prova.
- [ ] Preservar IDs de projetos já usados por links/assistente e adicionar o destino do VECOM.
- [ ] Conteúdo longo nos dois idiomas não quebra mobile nem navegação por teclado.
