# RASCUNHO T10 — Consolidar a transição e retirar os consumidores legados

**Estado: proposto, ainda não publicado.** Os IDs Txx não são números de issue.

## What to build

Integrar a experiência completa com um único sistema visual e motor, mantendo rotas e contratos e tornando metadados e documentação coerentes com o perfil.

Contexto: portfólio existente de Kauê Ruon Cardoso; preservar a referência aprovada, navegação HTML e os contratos públicos. Esta tarefa não autoriza publicação.

## Acceptance criteria

- [ ] Remover seleção temporária de shells, consumidores do loader/cursor/canvas globais e scripts órfãos confirmados; não apagar diretórios em massa.
- [ ] Nenhum serviço útil depende de loaderDone; existe um único main e uma única cena ativa.
- [ ] SEO, dados estruturados, manifest, texto para crawlers e documentação não repetem senioridade/stack antiga indevida.
- [ ] APIs, URLs, downloads e hashes preservados continuam acessíveis; não trocar backend ou domínio.
- [ ] CI executa comandos reais; tipos, testes e build passam ou falhas preexistentes ficam explicitamente identificadas.
- [ ] Preparar corte/reversão a partir de commit-base sem descartar trabalho local e sem publicar automaticamente.
