## Limites e cuidados

As novas imagens são propostas, não aprovações presumidas. O Atlas explora tipografia serifada editorial no contexto do projeto; isso não muda a tipografia global da marca pessoal. Placa e demais campos gerados são exemplos ilustrativos e deverão ser substituídos por dados demonstrativos preparados. A interface recriada não é prova funcional.

As posições e quebras de texto variam entre frames gerados; na implementação, título, resumo e CTA devem manter suas âncoras. O CTA de uma página dedicada deve avançar na história, ainda que o gerador repita Conhecer o projeto em algum enquadramento.

Conservar documentos/Formatador do Atlas e o conceito VECOM; não redesenhar os produtos originais. Nenhuma mudança de interface nesta rodada. V1 permanece preservada como histórico.
