## Uso no planejamento e produção

- Estas referências detalham a identidade específica de cada produto; a linguagem mineral/violeta do portfólio continua conectando a jornada.
- Abrir as imagens antes de preparar storyboards ou codar os cases. Descrições e nomes de arquivos não substituem a inspeção visual.
- Preparar assets separados e reproduções de interface adequados ao roteiro. Quando necessário, usar dados demonstrativos na reprodução pública.
- Os dashboards enviados contêm registros operacionais. Os originais ficam locais, excluídos do Git por regra específica; não foram publicados em GitHub nem copiados para assets públicos da aplicação.
- Não alterar os originais. Capturas preparadas para uso público serão materiais separados, com nomes e procedência próprios.
