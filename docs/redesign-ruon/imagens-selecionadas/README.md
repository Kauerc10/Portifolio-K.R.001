# Imagens selecionadas por Kauê

A seleção reúne onze referências para a próxima rodada. A composição recorrente usa títulos escuros e violetas, texto de apoio separado por filetes e textura mineral nas margens. Aplicar a fita violeta como transição pontual entre blocos para preservar seu impacto. O verde-sálvia, o bronze e o azul frio funcionam como detalhes locais.
