# Política de Segurança (Security Policy)

## 🛡️ Versões Suportadas

Utilizamos o modelo de suporte para a versão ativa em produção:

| Versão | Suportada |
| --- | --- |
| 2.x (Next.js 16 + Agente ÆVO) | :white_check_mark: |
| 1.x (HTML/Vanilla JS) | :x: |

## 📩 Reportando uma Vulnerabilidade

Se você identificar qualquer vulnerabilidade de segurança (ex: exposição inadvertida de dados ou falhas em endpoints da API), por favor **não abra uma issue pública**.

Envie um e-mail com os detalhes para **kaue.ruon@gmail.com**. Responderei em até 48 horas.
